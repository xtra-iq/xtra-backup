About the application

Xtra Backup uploads existing backup files from an authorized server to the Google Drive account selected by its owner and removes older uploaded backups according to the configured retention period. Each Google account authorizes access separately.

The application uses the Google Drive drive.file permission to create and manage files it creates or that the user explicitly makes available to it. It does not request access to all Google Drive files.

Privacy policy

Effective October 21, 2026.

The tool processes selected backup files, file names, sizes, timestamps, Drive file identifiers and OAuth credentials to provide uploads, duplicate detection and retention cleanup.

Backup files are sent from the configured server to Google Drive. Tokens, configuration and upload logs are stored on that server and may be accessible to its administrators. This website does not receive backup files or tokens.

Google user data is not sold, used for advertising or used to train generalized AI or machine learning models. Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Backups remain in the authorized Drive account until deleted by the account owner or configured cleanup. Local tokens and logs remain until removed by the server administrator. Google processing is subject to Google's policies.

You can stop scheduled backups, revoke application access in your Google Account third-party connections and ask your server administrator to delete local tokens and logs. Revoking access does not automatically remove uploaded backups.
